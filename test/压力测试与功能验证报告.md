## 七、审计溯源验证

以「面粉」这笔账为例：

**正向**（原话 → 分录）：

```
#1 [已入账] 记账   chat-1   「今天买了300块面粉」→ 面粉
#3 [已入账] 纠错   chat-1   「把今天那笔面粉改成480」→ 面粉
```

**反向**（分录 → 原话）：

```
分录「面粉」(^chat-1) ← #1 记账「今天买了300块面粉」
分录「面粉」(^chat-1) ← #3 纠错「把今天那笔面粉改成480」
```

同一笔分录上能同时看到「谁建的」和「谁改的」，改前/改后金额完整留档。

## 八、成本结转验证

| 场景 | 输入 | 结果 |
|---|---|---|
| 首次结转 | 账上 14,920.10，盘点 5,000 | 销售成本 9,920.10 ✅ |

累计校验：

```
两次结转累计成本 = 9,920.10 + 2,000 = 11,920.10
直接计算         = 14,920.10 − 3,000 = 11,920.10   ✅ 一致
```

## 九、测试中发现并修复的缺陷

| # | 缺陷 | 根因 | 修复 |
|---|---|---|---|
| 1 | 说「不行」却把账落了 | 确认词用单字子串匹配，「不行」命中「行」 | 否定词显式判断 + 判断顺序调整 + 回归测试 |
| 2 | 利润表收入显示为负数 | 收入已取正，接口又取负一次 | 去掉多余负号 |
| 3 | 两个单测随日期变红 | 检索默认只看 30 天，测试写死日期 | 测试改用相对今天 |
| 4 | 业主提款后现金反而增加 | 信任 AI 的 `transfer` 类型 | 按科目性质决定借贷方向 |
| 5 | 同一「面粉」有时归存货、有时归杂费 | 批量分类提示词缺示例 | 补 16 条 few-shot |
| 6 | Excel 导入把账本日期写成 `T10:00:00` | `datetime` 是 `date` 子类，未先判断 | 先判 `datetime` 再取 `.date()` |
| 7 | 转账把收入和支出双双虚增 | 互转两边同时计入统计 | 只统计真正的收入/支出 |
| 8 | 期初余额被算成「收入 53,000」 | 现金流入被当作经营收入 | 结转类单独归类，不计收支 |
| 9 | 改账后账本每条之间多空行 | `format_entry` 带尾换行又参与 join | 先 strip 再拼接 |
| 10 | 盘点数比账上多时无法纠正 | 直接报错，形成死路 | 改为生成冲回分录 |
| 11 | 结转结果显示「期间 undefined」 | 确认接口漏返回日期 | 补 `date_from/date_to` |
| 12 | 成本为 0 仍给「确认结转」按钮 | 未判断零成本 | 改为提示无需结转 |
| 13 | 改了代码浏览器仍显示旧页面 | 静态资源被缓存 | 加 `no-cache` 响应头 + 版本号 |
| 14 | 流水页白屏 `undefined.reduce` | 过滤函数漏写 `return` | 修复并加渲染冒烟测试 |
