# 使用指南：一家小店该怎么把账用起来

> 这份写给「不会会计、但得管好钱」的店主。
> 不讲借贷，只讲**什么时候做什么事**。

---

## 一、期初余额是干嘛的？（第一次用必看）

### 先讲一个真实场景

张老板开五金店三年，一直用纸笔记账。今天开始用这套软件。

他店里现在的实际情况是：

| 家底 | 金额 |
|---|---|
| 收银台里的现金 | 3,000 |
| 银行卡 / 微信 / 支付宝 | 45,000 |
| 仓库里压着的货 | 20,000 |
| 还欠着供应商的货款 | 8,000 |

**如果他不填期初余额会发生什么？**

第二天他记一笔「卖了 580 块门锁」，软件告诉他：

> 现金余额 **580.00** 元

可他明明手里有 3,580 块。**账和现实对不上，从此每一张报表都是错的。**

### 期初余额就是这个意思

> **把你「开始用软件这一刻」的家底告诉它，让账本的起点和现实一致。**

填完期初，软件会自动做一件事：

```
资产：现金 3,000 + 银行 45,000 + 存货 20,000 = 68,000
负债：应付 8,000
──────────────────────────────────────────
差额 60,000 → 自动记入「期初余额」科目

意思就是：这家店刨掉欠别人的，值 6 万块。
```

这个差额**不用你算**，软件自动平掉。它不是收入，也不是利润——它是**你过去三年攒下来的家底**。

### 三个常见问题

**Q：什么时候填？**
A：只有三种情况：
1. **第一次用**（必须）
2. **接手一家新店**
3. **新建一个账本**

**Q：多久填一次？**
A：**一辈子一次**（每个账本一次）。**不用每个月填**，也不用每年填。

**Q：不确定数字精确怎么办？**
A：**能填多准就填多准。** 差多少，以后每一张报表就跟着差多少。
但也不用死磕到分——大概到百位就可以开工了。

### 不填会怎样

现金会一路走负数，利润表、资产负债表全是假数。
**期初是账本的地基，不填就等于没打地基。**

## 二、多久结算一次？（这是最常问的问题）

先分清两件事，很多人会混：

| | 是什么 | 做什么 |
|---|---|---|
| **月末成本结转** | 算清楚这个月卖掉的货，进价是多少 | 盘一次货，填个数，软件自动算 |
| **关账/锁账** | 把过去的账锁死不让改 | **本软件不做，也不建议做** |

### 结论先说

> **每月结转一次；永远不要关账。**

### 为什么是「每月」

1. **月利润是经营的基本单位** —— 店主最常问的就是"这个月赚没赚"
2. **存货不盘会失真** —— 丢货、损耗、自己拿回家、送人，账上还挂着，越滚越假
3. **报税需要** —— 个体户通常季度预缴、年度汇算，底子都是月度数
4. **成本极低** —— 一次 5 到 15 分钟

### 为什么「不要关账」

小店经常事后发现记错了。你把账锁死，明天发现上个月多记了 500，就改不了了。

**本软件的设计是"随时能改"**：月末结转只是**补一笔分录**，不改历史。就算结转完了发现问题，照样能改，改完重新结一次就行。

### 按你的生意类型选

| 你的情况 | 建议 | 为什么 |
|---|---|---|
| **五金店 / 杂货店 / 便利店** | **每月盘一次货** | 存货是最大的资产，不盘账就是假的 |
| **餐饮 / 早点铺** | 每月盘，或按「销售额 × 成本率」估 | 食材每天进出，细盘不现实 |
| **理发 / 维修 / 家政（服务为主）** | **不用盘点**，进货直接记成本 | 几乎没有库存可盘 |
| 刚开店、流水很少（月流水不到 1 万） | 可以两三个月盘一次，**但别超过一个季度** | 再长失真就严重了 |
| 准备报税 | 至少**按季度**盘 | 报税要看真实利润 |

### 实在懒得盘点怎么办

用**成本率估算法**：五金店进货成本一般占销售额的六成左右。

```
假设本月卖了 50,000，成本率 60%
→ 直接按 30,000 结转成本（不用真盘）
```

**但这是估的**，报税或给会计看的时候，最好还是实际盘一次。

### 年度 vs 月度，冲突吗？

**不冲突，各管各的：**

- **月度**：给自己看，管经营决策
- **年度**：给会计/税务局看

**每月都盘了，年底自然就有全年数**，不用年底再补一次大的。

## 三、从零开始的完整流程

### 第一天（约 30 分钟）

```
1. 打开软件 → 选一个账本（或新建）
2. 进「期初」页 → 填店里的家底 → 保存
3. 进「设置 → 导入账单」→ 把微信/支付宝/银行的历史账单导进来
   （如果以前没记账，跳过这步）
4. 看一眼「报表」页，确认数字和现实对得上
```

### 每天（10 秒）

有收支就说一句：

```
「今天卖了 580 块门锁」
「进了 1200 块 PVC 水管」
「请师傅上门安装，人工费 400」
```

**不用每笔都记** —— 记大额的、能对上的就行。买瓶水这种不用记。

### 每周（1 分钟）

进「流水」页从上往下扫一遍：

- 有没有记错的？点开某一条能看到它从哪句话记出来的
- 记错了直接说：「昨天下午3点那笔耗材记错了，是80块」
- 想看某个品类：「搜 门锁」→ 这个月卖了多少一目了然

### 每月（5 到 15 分钟）

```
1. 盘一下仓库：还剩多少货（估个大概就行）
2. 「报表」页 → 最下面「月末成本结转」
3. 填入盘点数 → 试算 → 确认结转
4. 看利润表：这个月到底赚了多少
5. 「流水」页 → 导出表格 → 存起来或发给会计
```

**这一步不做，利润表就是虚的。**

### 每年（一次性）

```
导出全年流水 + 报表 → 交给会计 / 报税
```

## 四、四个常见误区

### ❌ 误区一：「我记流水就行了，不用管什么结转」

**后果**：利润表虚高。
进货的钱变成了「存货」（资产），不做结转就一直挂在资产上，利润表只看到收入看不到成本。

用真实数据说话：

```
不做结转：  收入 112,210  −  支出 49,754  =  净利 62,457   ← 虚高一倍
做了结转：  收入 112,210  −  支出 79,129  =  净利 33,081   ← 真实
```

**你以为赚了 6 万，实际赚了 3 万。**

### ❌ 误区二：「期初随便填个大概」

差多少，以后每一张报表就跟着差多少。这是地基。

### ❌ 误区三：「记账要每笔都记，不然不准」

不用。**记大额和能对上的账**，小额零钱忽略就行。
记账的目的是**看清经营**，不是给自己找活干。

### ❌ 误区四：「存货盘点太麻烦，以后再说」

一个月不盘，成本就是 0，利润虚高。
**拖三个月，账就没法看了。**

## 五、一张表总结

| 频率 | 做什么 | 花多久 |
|---|---|---|
| **一辈子一次** | 填期初余额 | 30 分钟 |
| **第一次用** | 导入历史账单 | 10 分钟 |
| **每天** | 说一两句收支 | 10 秒 |
| **每周** | 扫一眼流水，纠错 | 1 分钟 |
| **每月** | 盘点 + 结转 + 看利润 + 导出 | 5–15 分钟 |
| **每年** | 导出全年，交会计 | 10 分钟 |

**核心就两件事：平时随手记，月底盘一次。** 其他都是可选的。
