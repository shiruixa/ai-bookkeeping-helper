# 看账指南：四张表分别回答什么问题

> 「看账」页有四张表。很多人一打开就被数字淹没，其实每张表只回答**一个问题**。
> 先记住这四个问题，再看细节。

| 表 | 回答的问题 | 一句话 |
|---|---|---|
| **利润表** | 这段时间**赚了多少钱**？ | 收入 − 成本费用 = 净利润 |
| **资产负债表** | 到现在为止，我**有多少家底**？ | 资产 = 负债 + 所有者权益 |
| **科目余额表** | 账有没有记错？ | 借方合计必须等于贷方合计 |
| **科目明细账** | 这个科目的钱**怎么变成现在这样的**？ | 逐笔 + 余额累进 |

---

## 一、利润表 —— 「我这段时间赚了多少」

**看的是"一段时间的流量"，像流水账。**

```
项目                金额（元）
─────────────────────────────
营业收入
  销售收入          112,210.55
收入合计            112,210.55
─────────────────────────────
成本及费用
  营业成本          -29,375.55     ← 卖掉的那些货，进价是多少
  租金              -18,000.00
  工资              -22,034.15
  水电               -6,985.21
  杂费               -2,734.25
支出合计            -79,129.16
═════════════════════════════
净利润               33,081.39
会计期间  2026-07-01 至 2026-10-11
```

### 三个关键数字

| 看什么 | 怎么算 | 说明 |
|---|---|---|
| **收入合计** | 卖出去多少钱 | 不是利润，别高兴太早 |
| **营业成本** | 卖掉的货的进价 | **这一项最容易漏**，见下 |
| **净利润** | 收入 − 支出 | 真正赚到手的 |

### ⚠️ 最容易误读：营业成本

如果**不做月末成本结转**，利润表会变成这样：

```
收入合计   112,210.55
支出合计   -49,753.61     ← 没有营业成本这一项
净利润      62,456.94     ← 虚高！把进货钱藏进了"存货"这个资产里
```

原因是：进货时钱变成了**存货（资产）**，只有货卖掉了，才算**成本（费用）**。
不做这一步，利润表就把"还没卖掉的货"的钱也算成了利润。

**所以看利润表之前，先确认这个月的成本结转做了没有**（看账页最下方「月末成本结转」卡片）。

### 毛利率怎么看

```
毛利率 = (收入 − 营业成本) ÷ 收入
      = (112,210.55 − 29,375.55) ÷ 112,210.55 ≈ 73.8%
```

早餐店毛利率 60%–75% 属正常；如果算出来 90%+，八成是成本没结转。

## 二、资产负债表 —— 「我现在有多少家底」

**看的是"某一时点的存量"，像一张照片。**

```
项目                金额（元）
─────────────────────────────
资产
  银行存款           45,000.00
  现金               32,491.87
  存货               12,589.52
资产合计             90,081.39
─────────────────────────────
负债
  应付                3,000.00
负债合计              3,000.00
─────────────────────────────
所有者权益
  期初余额           56,000.00
  业主提款           -2,000.00     ← 老板拿走家用，所以减权益
  未分配利润         33,081.39     ← 等于利润表的净利润
权益合计             87,081.39
═════════════════════════════
负债和所有者权益合计  90,081.39

资产合计  90,081.39   负债和所有者权益合计  90,081.39   差额  0.00
```

### 怎么读

| 项目 | 含义 |
|---|---|
| **资产** | 钱和能用钱衡量的东西：现金、银行、仓库的货 |
| **负债** | 欠别人的：应付货款、借款 |
| **所有者权益** | 真正属于老板的部分 = 资产 − 负债 |

### ⚠️ 「业主提款」为什么是负数

老板从店里拿钱家用，**钱离开了生意**，所以是**减少权益**。
它显示为负数是对的 —— 表示"老板拿走的钱要从不属于他的部分里扣掉"。

**公司账和个人账必须分开**：老板拿钱自己花，记公司的「业主提款」，
不要和公司的经营支出混在一起。这就是"会计主体"原则。

### 最下方那行「差额」是干什么的

```
资产合计 90,081.39   负债和所有者权益合计 90,081.39   差额 0.00
```

**会计恒等式**：资产 = 负债 + 所有者权益。差额必须是 0。
不是 0 就说明账记错了。这是每张资产负债表自带的"体检报告"。

> ⚠️ **反过来不成立**：差额为 0 **不代表数字都对**。
> 比如把「现金」和「存货」搞混，两边都错，恒等式照样成立。
> 差额为 0 是**必要条件，不是充分条件**。

## 三、科目余额表（试算平衡）—— 「账有没有记错」

**这是给记账人自己看的体检表，不是给老板看的。**

```
科目        借方        贷方        余额
现金     152,300.00  119,808.13   32,491.87
存货      41,965.07   29,375.55   12,589.52
...
合计     288,304.78  288,304.78        0.00

借方合计 288,304.78   贷方合计 288,304.78   差额 0.00
```

**两条铁律**：
1. **借方合计 = 贷方合计** —— 复式记账的数学约束，不等就是有笔分录记错了
2. **余额那列全部加起来 = 0** —— 全账本余额之和恒为零

这两条能自动挡掉绝大多数录入错误。如果这里不平，别急着看利润，先查账。

## 四、科目明细账 —— 「这笔钱是怎么变成现在这样的」

**单科目的流水，带余额累进。** 用来回答"我们这个月现金都花哪儿了"。

```
日期        摘要              发生额        余额
2026-10-01  房租            -4,500.00   30,000.00
2026-10-03  包子              +680.00   30,680.00
2026-10-05  面粉              -880.00   29,800.00
```

页面上的科目按钮（现金 / 银行 / 存货 / 杂费）可以切换。

## 五、三张表之间的勾稽关系

这是判断"账是不是真的对"的关键 —— 三张表必须能对上：

```
利润表的「净利润」  =  资产负债表「未分配利润」的当期增加额
                     （33,081.39 = 33,081.39 ✓）

资产负债表「存货」  =  明细账里存货科目的期末余额
                     （12,589.52 = 12,589.52 ✓）

试算平衡表所有分录  =  账本里每一笔交易的原始记录
                     （每笔都能在明细账里找到）
```

**对不上的地方，就是问题所在。**

## 六、老板日常只看这五个数字

不用每次都看四张表。日常经营盯这五个就够：

| 数字 | 在哪张表 | 看什么 |
|---|---|---|
| **净利润** | 利润表 | 这个月到底赚没赚 |
| **收入合计** | 利润表 | 生意有没有变大 |
| **营业成本 / 收入** | 利润表 | 毛利率有没有下降 |
| **现金 + 银行存款** | 资产负债表 | 手里还有多少钱周转 |
| **存货** | 资产负债表 | 压了多少货在仓库 |

**特别提醒现金**：净利润是正的，但现金可能是紧的 —— 因为钱压在存货和赊账里。
**赚钱 ≠ 有钱花**，这是个体户最常见的困境。

## 七、什么时候该做成本结转

| 情况 | 要不要做 |
|---|---|
| 月底要出利润表给会计 / 报税 | **必须做** |
| 只是看看月底还剩多少钱 | 可以不做 |
| 想知道这个月真实赚了多少 | **必须做** |
| 刚接手账本，还没进过货 | 不用做 |

操作：看账页 → 「月末成本结转」→ 盘点仓库还剩多少货 → 填金额 → 试算 → 确认结转。

系统会自动算出：
```
本期销售成本 = 期初存货 + 本期进货 − 期末盘存
```

**做完整张利润表才是真的。** 这一步没做，"净利润"就是个乐观的估计值。
